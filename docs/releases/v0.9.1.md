# Bloodborne for Apple Silicon 0.9.1

A fix for walls and other scenery turning black after long play.

What's new:

- **Fixed: black walls and scenery.** The shader cache could save a new shader over an older one
  that other saved entries still used. Those entries then drew with the wrong shader on every later
  start, often as black walls, until the cache was deleted by hand. New shaders now never take the
  place of saved ones. Thanks to claitonllemes for tracking it down to the cache.
- **Your shader cache is rebuilt once:** the first time you play after updating, the game compiles
  its shaders again, so new areas can stutter briefly until each has been seen once. This also
  repairs a cache that is already showing black walls.
- **Slightly less processor time** while drawing: the threads that prepare draws no longer read a
  setting on every draw, so they are about 10% less busy. The frame rate does not change.

## Known issues

- A rare crash in the game's render thread (exit code 139) after long sessions is still being
  investigated. If it happens, please report it with the game's log.
- Blood on already killed enemies can look pale with bright edges after reloading a save.
- The camera after a cutscene sometimes starts in front of your character; move the camera to turn
  it around.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.0 again from the releases page.
