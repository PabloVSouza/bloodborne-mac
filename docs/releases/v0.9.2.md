# Bloodborne for Apple Silicon 0.9.2

Building the recompiled code works again, cloth no longer flutters at high frame rates, a rare
crash is guarded, and the recompiled code uses less memory.

What's new:

- **Fixed: building the recompiled code.** On the **Recompiled code** page (Settings), Build could
  stay on "Checking your game" forever while nothing happened, and Cancel did nothing. The build
  now starts, keeps going when you switch to another page, shows how many files are compiled as
  they finish, and Cancel stops it completely. A download that stalls now stops with a message
  instead of waiting forever. Thanks to claitonllemes for the report.
- **Fixed: a rare crash in long sessions.** The game could close (exit code 139) after hours of
  play, in the render thread at `0x2169edc`. Ported from bbport 0.7 (whp199's fix): an occlusion
  test the game could not create is created again or skipped. Thanks to claitonllemes for the
  detailed reports.
- **Fixed: cloth fluttering above 30 FPS.** Coats, capes and other cloth were stiffer the higher
  the frame rate and fluttered; they now move as at 30 FPS at any frame rate. From bbport 0.7.
- **Fixed: play time counted slow above 30 FPS.** The game dropped each frame's fraction of a
  millisecond, so the save's play time ran about 4% slow at 60 FPS; it is now counted in full.
- **Two guards from bbport 0.7** (by way of SrShadowy's fork): against a rare physics query that
  could fill memory until the game crashed, and against an invalid character id being written
  into a save.
- **Less memory with the recompiled code:** about 2 GB less at its peak (7.8 GB to 5.7 GB in
  Cathedral Ward on an M3 Pro), with the same frame rate. Macs with 16 GB have more room in heavy
  areas.
- **A little less processor time with the recompiled code:** more of the game's code runs
  compiled, and more of its library calls run natively (calls left to the translator: 69,600 a
  second to 9,400).

## Known issues

- On a 16 GB Mac the Forbidden Woods can run out of memory with the MoltenVK renderer
  ([#8](https://github.com/bloodborne-native/bloodborne-mac/issues/8)); we are still looking into
  it. The default Metal renderer and the recompiled code use less memory.
- Seamless co-op (BBSC) is not supported yet.
- Blood on already killed enemies can look pale with bright edges after reloading a save.
- The camera after a cutscene sometimes starts in front of your character; move the camera to turn
  it around.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.1 again from the releases page.

The recompiled code has to be built again with this version: the **Recompiled code** page says
so, and until then the game runs translated, as by default. Press **Build** (about 15 minutes,
about 3 GB free while it builds).
