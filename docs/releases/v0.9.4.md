# Bloodborne for Apple Silicon 0.9.4

Signing in to The Hunter's Dream from the launcher, and two fixes.

What's new:

- **Sign in to The Hunter's Dream.** The Online page now has a **Sign in** button instead of asking
  for an online ID and a token. The launcher shows a code and opens the server's page, and you
  approve the code there with Discord. Your sign-in is kept in a private file, and an online ID and
  token you entered before are kept. This is [SEKY443](https://github.com/SEKY443)'s work. Thank you!
- **The game no longer closes when it connects to The Hunter's Dream** (error 132), also by SEKY443.
- **Textures that were drawn dark** after long play under memory pressure now stay correct.

## Known issues

- On a 16 GB Mac the Forbidden Woods can run out of memory with the MoltenVK renderer
  ([#8](https://github.com/bloodborne-native/bloodborne-mac/issues/8)). Use the default Metal
  renderer (**Advanced → Renderer → Metal**): it uses less memory and is faster. If you played
  before 0.9, check this setting: earlier versions used MoltenVK by default.
- Blood on already killed enemies can look pale with bright edges after reloading a save.
- The camera after a cutscene sometimes starts in front of your character; move the camera to turn
  it around.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.3 again from the releases page.

If you built the recompiled code with 0.9.2 or 0.9.3, it keeps working: nothing to do.
