# Bloodborne for Apple Silicon 0.9.0

The game now draws with Apple's Metal directly, plays online, and can run its code compiled for
your Mac. This release brings together the two release candidates and what came after them.

What's new:

- **Native Metal renderer by default:** the game draws with Metal without loading Vulkan or
  MoltenVK. On an M3 Pro at native 1080p it runs at about 38 FPS where MoltenVK runs at about 30
  in the same place. MoltenVK stays as a fallback in Advanced → Renderer.
- **Online play:** messages, bloodstains and summons through Seamless Hunt or The Hunter's Dream,
  chosen on the launcher's **Online** page. Everyone in a session must use the same pool.
- **Save editor** (Saves → **Edit character**): Blood Echoes, Insight and attributes; items,
  weapons, armor and blood gems; a weapon's level and imprint; gems in and out of weapon slots.
  The launcher backs up the full save before every edit. An edited save can't earn trophies and
  plays offline only.
- **Recompiled code** (new since RC 2; in the launcher's menu, under Settings): the launcher
  compiles the game's code for your Mac once, from your own copy, and the game then uses 7–14%
  less processor time in our tests (the frame rate stays about the same: on a Mac the graphics set
  the pace). Building takes about 15 minutes on an M3 Pro and about 3 GB free while it runs; no
  Xcode is needed. *Translated while playing* stays the default.
- **Faster game code** (new since RC 2): the translator calls the port's own functions directly
  and finds branch targets faster, and common math and text functions run natively: 3.6% less
  processor time per frame on an M3 Pro.
- **The game's threads on the performance cores** (new since RC 2): where the processor sets the
  pace, about 2 FPS more (59 to 61 FPS in Yahar'gul on an M1 Max, measured by contributor
  FraSharp). On Macs where the graphics set the pace, nothing changes.
- **Button prompts for the device in use,** keyboard and mouse in the in-game menu, and keys that
  can be remapped to combinations with Shift, Ctrl or Alt.
- **A new launcher look** with **Saves** and **Trophies** in the menu, the in-game menus in the
  same colours, and texts rewritten in all 20 languages.
- **MetalFX** runs on the native frame; the upscaler is now off by default. FSR 3.1 and FSR 4.1.1
  work with the MoltenVK renderer.
- **Fixed:** opening the status page in the Lecture Building, or quitting, could stop the game
  with the Metal renderer; closing the on-screen keyboard after typing a name could open it again
  at once, several times in a row; a rare wrong result when the game converts a large number to an
  integer (the last two new since RC 2).
- **macOS 15 or later** is required.

## If you tested a release candidate

The launcher of 0.9.0 RC 1 and RC 2 does not tell you about this release: download it from the
releases page. Your saves, settings and backups carry over as they are.

## Known issues

- Blood on already killed enemies can look pale with bright edges after reloading a save.
- The camera after a cutscene sometimes starts in front of your character; move the camera to turn
  it around.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.8.3 again from the releases page.
