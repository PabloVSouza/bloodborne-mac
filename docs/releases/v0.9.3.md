# Bloodborne for Apple Silicon 0.9.3

A third faster on the default renderer, less processor time, and the recompiled code no longer has
to be built again after an update.

What's new:

- **About a third faster.** Textures are now made so that Apple's GPUs can compress them, which they
  do without any loss of quality. On an M3 Pro at native 1080p, standing in Iosefka's Clinic: 48–49
  FPS instead of 36–37. Macs with less memory bandwidth gain the most. This is
  [MojahedAbushawish](https://github.com/MojahedAbushawish)'s work for
  [bloodborne_mac_port](https://github.com/Wooloomooloo2/bloodborne_mac_port) (#33), adapted to
  this renderer. Thank you!
- **Less processor time.** The threads that prepare each frame for the GPU now run on the fast
  cores, and a diagnostic that ran on every player's game is now off by default. The frame rate is
  the same on a Mac, with slightly less processor time.
- **The recompiled code keeps working after updates.** A library built with 0.9.2 is still used by
  0.9.3, so there is nothing to rebuild. When a later version of the recompiler is available, the
  **Recompiled code** page (Settings) offers **Update**, which compiles only what changed: seconds
  to a few minutes instead of about 14. To make that possible, the library now keeps what it
  compiled: it takes about 710 MB instead of 330 MB.
- **Less processor time with the recompiled code:** the game functions the port's fixes hook into
  (the crash guard from 0.9.2 among them) now run compiled too, instead of translated.
- **The Recompiled code page** shows each step while the library builds.
- **A crash at startup is recovered from:** if the game ever closes while loading its saved
  graphics pipelines (a damaged cache file), the next start replaces that file and starts normally.

## Known issues

- On a 16 GB Mac the Forbidden Woods can run out of memory with the MoltenVK renderer
  ([#8](https://github.com/bloodborne-native/bloodborne-mac/issues/8)). Use the default Metal
  renderer (**Advanced → Renderer → Metal**): it uses less memory and is faster. If you played
  before 0.9, check this setting: earlier versions used MoltenVK by default.
- Blood on already killed enemies can look pale with bright edges after reloading a save.
- The camera after a cutscene sometimes starts in front of your character; move the camera to turn
  it around.
- Plants can sometimes move unevenly, as if skipping frames.

## Install or update

Download the Apple Silicon DMG and replace Bloodborne.app. Saves and settings remain in
`~/Library/Application Support/bloodborne_mac`; the launcher backs up your saves before every
start. No game files are included: supply your own Bloodborne dump with update 1.09. To go back,
install 0.9.2 again from the releases page.

If you built the recompiled code with 0.9.2, it keeps working: nothing to do.
